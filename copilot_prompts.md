# GitHub Copilot Prompts – Python Adventure Game

## Prompt 1 – Project Setup and Planning

I am completing a beginner-level Python course project called "Building a Python Adventure Game with GitHub Copilot".

I am a beginner learning Python. Help me build this project step by step using GitHub Copilot.

First, inspect my current `adventure_game.py` file and understand its existing contents.

Do not modify the entire file at once. Guide me through the project in stages, explaining what each function does and why it is needed.

Keep the code beginner-friendly, readable and properly structured. Avoid unnecessarily advanced Python concepts.

## Prompt 2 – Building the Game

I want to develop a text-based Python Adventure Game.

Help me implement the game using the following functions:

- `start_game()` – Introduce the game, welcome the player and begin the adventure.
- `forest_path()` – Handle the forest adventure and its decisions.
- `cave_path()` – Handle the cave adventure and its decisions.

The game should include:

1. Player name input.
2. An introduction to the adventure.
3. Multiple paths and choices.
4. Different outcomes depending on the player's decisions.
5. Winning and losing scenarios.
6. Invalid-input handling.
7. An option to replay the game.

Use simple Python concepts such as functions, conditional statements, loops and user input.

Implement the game in manageable stages rather than generating everything at once. Explain the code as you build it.

## Prompt 3 – Copilot Development Test

Check my current Python file, `adventure_game.py`.

I am a beginner learning Python. Help me build a text-based adventure game one function at a time.

Start by explaining how to create the `start_game()` function.

Do not modify my entire project at once.

## Prompt 4 – Final Game Generation

Review my existing `adventure_game.py` file and help me complete the Python Adventure Game.

The game must include:

- A `start_game()` function.
- A `forest_path()` function.
- A `cave_path()` function.
- Player name input and a welcome message.
- Interactive choices and branching paths.
- Different winning and losing outcomes.
- Proper handling of invalid inputs.
- A replay option that allows the player to restart the game.

Ensure that all functions work together correctly.

Keep the code beginner-friendly and easy to understand. Use appropriate print statements to communicate with the player.

Do not introduce unnecessary complexity.

## Prompt 5 – Testing and Debugging

I tested my `adventure_game.py` file and one or more test cases failed.

Review my existing code, identify the cause, and fix the problem while preserving the assignment requirements.

Review the complete `adventure_game.py` project.
