# Python Adventure Game

A text-based adventure game developed using Python and GitHub Copilot. Explore different locations, make decisions, face challenges, and experience different outcomes based on your choices.

## About the Project

Python Adventure Game is an interactive command-line game built using fundamental Python programming concepts.

Players begin their adventure by entering their name and choosing different paths. Their decisions influence how the story progresses, leading to different outcomes, including winning and losing scenarios.

GitHub Copilot was used as an AI-powered coding assistant during the development process.

## Features

- **Interactive Gameplay:** Play through a text-based adventure.
- **Player Personalization:** Enter your name before starting the game.
- **Multiple Locations:** Explore different paths, including forests and caves.
- **Decision-Based Gameplay:** Make choices that influence the adventure.
- **Multiple Outcomes:** Experience different winning and losing scenarios.
- **Input Validation:** Handles invalid user inputs.
- **Replay Option:** Restart the game and play again.

Before using the project, make sure you have:

- Python 3.x installed.
- Visual Studio Code installed.
- GitHub Copilot extension installed in VS Code.

## Setting Up GitHub Copilot in VS Code

**Step 1: Open Visual Studio Code**

Launch VS Code on your computer.

**Step 2: Open Extensions**

- Click the Extensions icon in the left sidebar.
- Alternatively, press `Ctrl + Shift + X`.

**Step 3: Install GitHub Copilot**

- Search for `GitHub Copilot`.
- Select the official extension published by GitHub.
- Click **Install**.

**Step 4: Install GitHub Copilot Chat**

- Search for `GitHub Copilot Chat`.
- Install the official GitHub extension if it is listed separately.

**Step 5: Sign in to GitHub**

- Open the Copilot interface in VS Code.
- Select **Sign in to GitHub**.
- Complete the authentication process in your browser.
- Return to VS Code.

**Step 6: Start Using Copilot**

Open your Python file and start writing code. GitHub Copilot can provide code suggestions and help explain or improve your code.

Note: Copilot features and availability depend on your GitHub account's eligibility and plan.
